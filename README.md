# Vyshu (Gundu) - Birthday Celebration Web App ✨

An interactive 3D birthday celebration single-page application built with React, Vite, Tailwind CSS, and Framer Motion.

## Features
- **3D Interactive Photo Showcase**: Real-time spring-physics tilt cards that respond to cursor and touch.
- **Friendship Bento & Gundu Chronicles**: Highlights, stats, and core squad memories.
- **3D Gift Box Wish**: Interactive 3D gift box unwrap with confetti cannons and birthday scroll reveal.
- **Floating Music Player**: Vinyl disk audio player with smooth toggle controls.
- **Mobile Responsive**: Optimized across smartphones, tablets, and desktops.

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```
